# ZIP del Ministeri de l'Interior

El Ministeri no deixa connectar des de GitHub. Per afegir una elecció que no és
al mirall (2023 i posteriors):

1. Baixa des de l'ordinador el fitxer «…_MESA.zip» d'infoelectoral.interior.gob.es
   (Àrea de descàrrega → tipus d'elecció i data → «Mesa»). Per exemple:
   - https://infoelectoral.interior.gob.es/estaticos/docxl/apliextr/04202305_MESA.zip (municipals 2023)
   - https://infoelectoral.interior.gob.es/estaticos/docxl/apliextr/02202307_MESA.zip (Congrés 2023)
   - https://infoelectoral.interior.gob.es/estaticos/docxl/apliextr/07202406_MESA.zip (europees 2024)
2. Puja'l en aquesta carpeta (GitHub → Add file → Upload files), sense canviar-li el nom.
3. Llança el workflow «Resultats electorals».
